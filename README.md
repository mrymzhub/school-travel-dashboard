# School Mode of Travel Dashboard

This dashboard shows how students travel to school using UK data. It helps promote sustainable transport modes.

##  Dashboard Preview
## Screenshots are saved in the same folder

##  Features

- Key metrics: total students, total schools, most common transport mode.
- Transport mode bar and pie charts.
- Top 10 schools by student count.
- School-level filter and data download option.
